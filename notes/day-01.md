# Day 1 - DevOps Workstation

## What I Learned

DevOps connects software development and IT operations.

The aim is to make software delivery faster, safer and more reliable.

DevOps involves building, testing, deploying, monitoring and improving systems.

## Important Terms

Source code is the code used to build an application.

Infrastructure includes servers, networks, databases and storage.

Deployment means releasing an application so that users can use it.

Monitoring means watching a system to check its health and performance.

A runbook contains instructions for operating or fixing a system.

## Why I Want to Learn DevOps

I want to learn how to build, deploy, automate, secure and monitor reliable systems using AWS.

## System I Would Like to Make More Reliable

I would like to learn how to build a real application on AWS and make sure that it remains available, secure and easy to update.
